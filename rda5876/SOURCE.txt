tools/generate_rda_tables.py uses the C preprocessor to extract the complete
rda_trap_12 and rda_pskey_12 tables. __RDABT_ENABLE_SP__ is defined (SSP).
BT_UART_BREAK_INT_WAKEUP is undefined: this board uses ordinary H4 UART
without a UART-break wake line. No optional UART filter patch is selected.
The manufacturer selects this table for __RDA_CHIP_R12_5876__.

PSKEY 0x80000074 uses the receiver's known 0x05025010 no-external-32k setting.
PSKEY 0x800000a8 retains its 0x0bbfbf30 power floor. All other selected SDK
PSKEY values are unchanged. The SDK's ordinary UART filter selection and
unsniff prerxon commands are sent before installing traps, in SDK order.
Board RF values, UART baud and Bluetooth identity are retained from the
supplied receiver evidence.
The six undocumented stock RAM policy overrides are not applied.
